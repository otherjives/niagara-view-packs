PointTagStyler view pack

This pack is designed to be rendered inside a station as a component view, where it can read the program's slots live and invoke its actions. The widget is entirely self-contained in widget.js — markup and styles are inlined, so it fetches nothing at runtime.

Open it with either:

/ord/station:|slot:/PointTagStylerV9|view:?fullScreen=true
/file/views/point-tag-styler-2.0.0/index.html?ord=slot:/PointTagStylerV9

A static preview would show nothing meaningful: every number in the real view comes from the live program's report slot.
